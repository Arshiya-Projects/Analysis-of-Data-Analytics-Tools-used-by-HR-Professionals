# Analysis Notes

The report describes the following analytical workflow:

1. Collect primary survey responses using Google Forms.
2. Export responses to CSV.
3. Clean and standardize the data using Python.
4. Use Pandas for loading, cleaning, and transformation.
5. Use Matplotlib and Seaborn for descriptive visualization.
6. Use cross-tabulation and Chi-square tests for categorical relationships.
7. Present findings using charts and a Tableau dashboard.

The report also notes that responses were handled confidentially and anonymously and used for academic purposes.
